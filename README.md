# Dio-Keylogger
Desafio aulas Ramsomware e Keylogger
Realizado curso acerca dos possíveis ataques envolvendo malwares do tipo ramsomware e utilizando um código Keylogger.
Inicialmente efetuado estudo com ramsomware, visando detectar arquivos específicos e criptografá-los, deixando aviso do que fora realizado. Em seguida, efetuado estudo de descriptografia com a chave gerada.
Sequencialmente, estudado código com keylogger, visando registro das teclas utilizadas por um usuário, sua execução em segundo plano e envio automático via email.
